- 実査日: 2026年8月16日（JST）
- 対象: `/`、`/device-campaigns`
- 主目的: 訪問者が比較内容を理解し、自分に合うキャンペーンを納得して選び、公式ページへ進めるかを確認する
- 判定: **NO-GO（現状のまま公開不可）**

## 1. エグゼクティブサマリー

現行ページは、比較対象・ランキング基準・MNP／新規番号の切り替え・SIMのみ／端末購入ありの分岐を理解しやすく提示できています。PC 1280×720、スマートフォン360×800の実査では、ページ全体の意図しない横スクロールや画像欠落は発生せず、主要なページ内導線も機能しました。

一方、公開可否に直結するP0項目で不合格があります。特に端末ランキングの上位データが現在の公式情報と一致せず、公式画像とサイト内のポイント表示が同一画面で矛盾しています。ユーザーが誤った金額をもとにキャンペーンを選ぶ可能性があるため、修正と再検証が終わるまで公開不可と判断します。

## 2. 公開を止める重大事項

### QAB-001: Apple Watchキャンペーンのポイントが25,000ではなく3,300

- 重要度: P0 / Critical
- 対象: `/device-campaigns` のMNP・新規番号ランキング1位、キャンペーンコード2602
- サイト表示: 25,000ポイント
- 現在の公式表示: 3,300ポイント
- 公式情報: [Apple Watch購入＆電話番号シェアサービス加入キャンペーン](https://network.mobile.rakuten.co.jp/campaign/apple-watch-number-share/)
- 追加矛盾: サイトで使用中の公式画像には「3,300ポイント」と記載されている一方、画像横の獲得ポイント欄には「25,000ポイント」と表示される
- 影響: 端末ランキング1位、詳細説明、メリット文言、ランキング順位が誤る

### QAB-002: Android製品購入キャンペーンのポイントが13,000ではなく6,000

- 重要度: P0 / Critical
- 対象: `/device-campaigns` のMNPランキング2位、キャンペーンコード2006
- サイト表示: 13,000ポイント
- 現在の公式特典: 6,000ポイント
- 公式情報: [対象Android製品購入キャンペーン](https://network.mobile.rakuten.co.jp/campaign/start-point/)
- 原因候補: 公式ページの「最大23,000ポイント」は、コード2091の10,000ポイント、コード2006の6,000ポイント、機種によってコード3303の7,000ポイントなどを組み合わせた総額。コード2006単体を13,000ポイントとして扱うと、コード単位比較と整合しない
- 影響: ランキング順位と獲得額が誤り、別キャンペーンとの二重計上を招く

### QAB-003: Rakuten認定中古キャンペーンの固定値引きが欠落

- 重要度: P1 / High
- 対象: `/device-campaigns` のMNPランキング5位、キャンペーンコード3297
- サイト表示: 固定ポイント0、値引き額は確定していない旨を掲載
- 現在の公式表示: 対象製品は22,000円割引、iPhone SE（第3世代）は15,000円割引
- 公式情報: [Rakuten認定中古製品](https://network.mobile.rakuten.co.jp/product/rakuten-certified/)
- 影響: 固定ポイント0という順位自体は算定ルールどおりだが、ポイント以外の実質的なお得さを掲載するというページの価値を満たせない

### QAB-004: 「情報を見る」CTAがエントリー用ログインへ遷移

- 重要度: P0 / High
- 対象: `/` の結論セクション、社員紹介キャンペーンのランキング行
- CTA文言: `公式ページの情報を見る` または `公式ページ`
- 実際の遷移先: `https://r10.to/hkD5ah` から楽天アカウントのログイン／キャンペーン参加導線へ遷移
- 本来の情報ページ: [社員紹介キャンペーン公式情報](https://network.mobile.rakuten.co.jp/campaign/referral-application-employee/)
- 影響: 「情報確認」と「エントリー」の意図が一致せず、ユーザーの期待を裏切る
- 補足: 詳細セクションでは2導線が区別されているが、結論セクションとランキング表では区別されていない

### QAB-005: 「2026年8月最新」の根拠となる全体確認日が見えない

- 重要度: P0 / High
- ページ見出しは「2026年8月最新」だが、ランキングデータ全体の確認日は画面に表示されていない
- データ一覧の確認日は2026年7月31日、画像の確認日は主に2026年8月6日で分離している
- 各画像の確認日は詳細に表示されるが、ポイント・条件・順位の確認日であるとは判断できない
- QAB-001、QAB-002、QAB-003の不一致があるため、「最新」の実質的な裏付けも満たしていない

### QAB-006: 費用条件と進呈条件がランキング上で見落とされる

- 重要度: P0 / High
- Apple Watchランキング行は条件を先頭3件に省略するため、「電話番号シェアサービス加入」と月額550円がランキング上に表示されない
- 分割進呈、受取操作、ポイント有効期限などが詳細記事に一貫して掲載されていない
- 影響: 金額だけを見て公式ページへ進み、適用条件や実質負担を後から知る可能性がある

## 5. ユーザーテスト

外部のテスト参加者を使った5人以上のユーザーテストは、本実査では実施していません。実在ユーザーの結果を代替・推測せず、公開ゲートは未達のままとします。

専門家ウォークスルーのみ、次の結果でした。

| ケース | 暫定判定 | 所見 |
|---|---|---|
| 初回申込・MNP・SIMのみ | 合格 | MNPが初期選択で、上位候補と条件を比較できる |
| 初回申込・新規番号・SIMのみ | 合格 | タブ切り替え後に新規番号向け順位へ正しく変わる |
| 2回線目以降 | 要改善 | 専用フィルターがなく、初回限定キャンペーンを読み飛ばしながら手作業で探す必要がある |
| 端末も同時購入 | 不合格 | 上位キャンペーンの獲得額が公式と不一致で、正しい選択を保証できない |
| 条件の簡単さを重視 | 要改善 | 順位が固定ポイント額のみで、条件の簡単さによる並べ替えや絞り込みがない |

公開前ユーザーテストでは、各参加者に以下を記録すること。

- 10秒後に説明できたページの用途
- 候補決定までの時間
- 選んだキャンペーン名、理由、理解した主要条件
- SIM／端末、MNP／新規番号の取り違え
- 公式導線の発見可否
- 誤った適用可否・受取額の確信有無

## 8. 再公開判定条件

次をすべて満たした時点で再度GO／NO-GO判定を行う。

1. 本レポートのP0「不合格」「要改善」がすべて合格になる
2. SIM・端末それぞれのMNP／新規番号上位5件を公開当日に公式ページと再照合し、不一致0件になる
3. 公式画像、ポイント表示、説明文、ランキング順位が一致する
4. 外部リンク30件を再確認し、情報閲覧とエントリーの導線が文言どおりに分離される
5. 5人中4人以上が補助なしで正しい候補と公式導線へ到達し、重大な誤選択が0件になる
6. Safari、Chrome、Edge、Firefoxの主要操作確認を完了する

Netlifyのビルド方式、リダイレクト、404、SEO、Core Web Vitals、独自ドメイン、HTTPSは、本レポートの価値提供QAがGOになった後の技術公開ゲートで検証する。
